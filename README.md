# Aussprachetraining Deutsch 🗣️

A free browser-based pronunciation trainer for A1 German learners. Words appear one at a time — read them aloud, click to hear the correct pronunciation, then move on.

## 👉 [Open the trainer here](https://ivoniet-ntu.github.io/german-pronunciation-trainer)

No download, no login. Works on phone and desktop.

## How it works

Each round presents words randomly from a curated list. The student reads the word aloud, then clicks it to hear the correct German pronunciation via text-to-speech. No translations or IPA are shown — deliberate, to encourage reading rather than memorising.

## Rounds

| Round | Focus |
|-------|-------|
| Leserunde A | Basic vowels and simple consonants |
| Leserunde B | Umlauts — ä, ö, ü |
| Leserunde C | Tricky consonants — j, w, v, qu, z, y |
| Leserunde D | Consonant clusters — ng, pf, tz, sp, st, ch |
| Leserunde E | Final consonant devoicing and r-vocalisation |
| Challenge | Longer and more complex words |
| Komplettrunde | All words from all rounds, shuffled |

## Features

- Adjustable audio speed (0.5x – 1.1x)
- Progress tracking per round (resets manually)
- Reshuffle button to repeat a round in a new order
- Click any word to hear it spoken aloud
